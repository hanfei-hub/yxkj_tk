# 益行跨境 Web 前端

这是 PySide6 客户端的 Web 端前端实现，位于 `web/`，不修改后端接口。

## 本地运行

在 `web/` 目录启动任意静态服务器，例如：

```powershell
python -m http.server 5173
```

然后打开 `http://127.0.0.1:5173`。前端默认连接 `http://120.26.207.89:8000`，也可以在浏览器控制台执行：

```js
localStorage.setItem("tk_api_base", "http://127.0.0.1:8000")
```

当前已覆盖登录、智能选品、选品库、新品榜单、采集箱、教师看板、个人中心和管理员同步入口。后续页面继续复用同一套 API 客户端即可扩展完整配置表单和店铺管理流程。
